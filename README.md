## 🏁 BRAKE FAILURE (`/racing/`)
브레이크가 고장난 채 9차선 고속도로를 질주하는 **자동 가속 레이싱** 게임 (탑다운 시점).

- 속도는 **초당 +2.5 ~ +7.8 km/h**로 계속 올라가며 절대 줄지 않는다 (차량마다 다름, 상한 480 km/h)
- **9차선 도로 · 왼쪽 차선일수록 흐름이 빠르다**
  `1차선 200 / 2차선 180 / 3차선 160 / 4차선 145 / 5차선 130 / 6차선 115 / 7차선 100 / 8차선 85 / 9차선 70 (km/h)`
- 내 속도보다 빠른 차선에서는 **뒤차가 덮치고**, 속도가 붙으면 느린 차선의 차량이 벽이 된다
- 트래픽 차량은 일정 확률로 **차선을 변경**한다 (깜빡이로 예고, 시간이 갈수록 확률 증가)
- 차량 8종 · 스탯(시작속도 / 가속 / 조향 / 차폭 / 점수배율)이 모두 다르다
- 7가지 배경 씬(여명의 도시, 사막, 네온 나이트, 설원, 해안, 황혼의 숲, 화산)이
  **점점 짧은 간격으로** 교체되며 속도감을 키운다 (씬 유지시간 x0.9씩 감소, 최소 7초)
- 위에서 내려다보는 **탑다운 시점**이라 회피 판단에만 집중할 수 있다
- 도로는 트랙 루프 없이 **무한히 이어지는 직선** (지면/노면 교차 밴드로 스크롤 감각)
- 노면 스크롤이 속도에 **비선형(1.72제곱)** 으로 반응해 100km/h와 480km/h의 체감 차이가 17배까지 벌어진다
- 속도가 오를수록 화면이 축소되어 앞을 더 멀리 보여준다 (고속에서도 회피 가능)
- 속도에 따라 화면 흔들림 · 속도선 · 비네트 · 파티클이 강해진다
- 충돌 판정은 그림보다 작은 히트박스(가로 60% / 세로 66%)로 넉넉하게 잡았다
- 우측 레이더가 화면 밖 먼 거리(약 3화면)까지 보여줘 미리 경로를 잡을 수 있다
- 트래픽끼리는 차간 거리를 유지하며 앞차를 따라잡으면 감속한다 (겹침 없음)

**사운드** (WebAudio 합성, 음소거 토글)
- 6단 기어 엔진음 — 변속할 때마다 RPM이 떨어졌다 다시 차오른다
- 톱니 2개(디튠) + 사각 서브를 로우패스로 묶은 배기음, RPM에 따라 컷오프가 열린다
- 노면 럼블 / 바람 / 고속 쉬익 노이즈가 속도에 따라 급격히 커진다 (속도 체감의 핵심)
- 옆을 스쳐 지나갈 때 좌우로 패닝되는 '휘익', 아슬아슬 통과 시 콤보 블립
- 충돌 시 금속 파열음과 함께 엔진·바람이 급정지한다

조작: `←` `→` (또는 `A` `D`) 차선 변경, `Enter` 시작/재시작, `Esc` 메뉴, 모바일은 화면 좌/우 터치.
