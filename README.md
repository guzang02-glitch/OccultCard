## 🏁 BRAKE FAILURE (`/racing/`)
브레이크가 고장난 채 9차선 고속도로를 질주하는 **자동 가속 레이싱** 게임 (탑다운 시점).

- 속도는 **초당 +2.5 ~ +7.8 km/h**로 계속 올라가며 절대 줄지 않는다 (차량마다 다름, **속도 상한 없음**)
- **9차선 도로 · 왼쪽 차선일수록 흐름이 빠르다**
  `1차선 200 / 2차선 180 / 3차선 160 / 4차선 145 / 5차선 130 / 6차선 115 / 7차선 100 / 8차선 85 / 9차선 70 (km/h)`
- 내 속도보다 빠른 차선에서는 **뒤차가 덮치고**, 속도가 붙으면 느린 차선의 차량이 벽이 된다
- 일반 차량은 **차선을 바꾸지 않는다.** 자기 차선을 지키며 앞차를 따라잡으면 감속만 한다
- 플레이어 차량 2종 — **빨간 스포츠카**(차폭 292 / 배율 x1.5) 와 **빨간 오토바이**(차폭 148 / 배율 x1.0)
  폭이 절반이고 조향도 빠른 오토바이가 더 쉬우므로 점수 배율은 스포츠카가 높다
- 도로 위 일반 차량 **15종** — 경차 · 해치백 · 세단 · 택시 · 쿠페 · 머슬 · 왜건 · SUV · 밴 ·
  픽업 · 카고트럭 · 탑차 · 버스 · 세미트레일러 · 스쿠터. 크기에 따라 실루엣과 장식이 모두 다르고
  색은 무작위(택시만 노랑 고정), 플레이어와 헷갈리지 않도록 붉은 계열은 제외
- 배경은 **하나로 고정**(여명의 도시). `racing/game.js` 의 `SCENE_ID` 를 바꾸면
  다른 배경(사막 / 네온 나이트 / 설원 / 해안 / 황혼의 숲 / 화산)으로 달린다
- 위에서 내려다보는 **탑다운 시점**이라 회피 판단에만 집중할 수 있다
- 도로는 트랙 루프 없이 **무한히 이어지는 직선** (지면/노면 교차 밴드로 스크롤 감각)
- 노면 스크롤은 속도에 **정비례**한다 (100km/h 당 초당 약 200px)
- 속도가 오를수록 화면이 축소되어 앞을 더 멀리 보여준다
  (제곱근 곡선으로 초반부터 시야를 확보하고 **기준 800km/h**에서 최소, 그 이후로도 조금씩 계속 축소)
- 속도에 따라 속도선과 비네트가 강해진다 (화면 흔들림 · 날씨 파티클 없음)
- 차선은 **끊김 없는 실선**, 노면은 단색이라 도로 위에 깜빡이는 무늬가 없다.
  스크롤 감각은 도로 밖 지면 밴드(1140km/h 에서 1.7개/초)와 도로변 오브젝트가 담당한다
- 충돌 판정은 그림보다 작은 히트박스(가로 60% / 세로 66%)로 넉넉하게 잡았다
- 우측 레이더가 화면 밖 먼 거리(약 3화면)까지 보여줘 미리 경로를 잡을 수 있다
- 트래픽끼리는 차간 거리를 유지하며 앞차를 따라잡으면 감속한다 (겹침 없음)
- 트래픽은 **정원 대비 가장 비어 있는 차선**에 투입된다 (50 → 91대).
  차선 정원은 좌측이 조금 더 많아 **1차선이 9차선보다 약 20% 붐빈다**
- 차선이 정해지면 그 차선에 맞는 차종을 뽑는다. **차폭이 클수록 우측(저속) 차선에 몰린다**
  (대형차 비율: 1차선 11% → 9차선 70%, 평균 차폭 285 → 343). 쿠페·머슬은 좌측,
  스쿠터는 우측을 선호하도록 별도 지정
- 새 차량은 **플레이어가 볼 수 없는 곳에서만** 생성된다. 화면 밖(축소율과 차량 길이를 반영해
  스프라이트가 조금도 걸치지 않는 위치)이면서, **레이더 표시 범위 바깥**에서 만들어 자연스럽게
  흘러 들어온다 (실측: 480회 생성 중 화면 침범 0건 · 레이더 침범 0건, 147~1655km/h 구간)
- 생성 시 그 차선의 빈 구간을 계산해 **겹치지 않는 자리에만** 넣는다. 자리가 없으면 만들지 않고
  다음 프레임에 다시 시도하므로, 겹쳐서 뒤로 밀려나는 현상이 없다 (실측 밀림 0건)
- 도로 양옆에 인도(연석 포함)가 이어지고, 그 밖으로 도시 건물이 들어선다
- 도로변 오브젝트는 스프라이트의 안쪽 끝을 갓길 밖에 고정해 **도로를 절대 침범하지 않는다**
  (폭이 커서 자리가 부족하면 화면 밖으로 넘긴다)

**사운드** (WebAudio 합성, 음소거 토글)
- 배경음(A 마이너 Am-F-C-G 4마디 루프, 132BPM)을 직접 합성해 재생한다
  - 킥/스네어/하이햇 + 톱니 베이스 + 스퀘어 아르페지오, 16분음표 룩어헤드 스케줄러
  - 속도가 오르면 필터가 열리고 하이햇이 촘촘해지는 정도로만 반응한다
- 엔진 험은 아주 작게만 (게인 0.05~0.075, 40~100Hz 저역 험). 속도에 따라 음높이만 조금 올라간다
- 옆을 스쳐 지나갈 때 좌우로 패닝되는 '휘익', 아슬아슬 통과 시 콤보 블립
- 충돌 시 금속 파열음과 함께 배경음이 끊긴다

조작: `←` `→` (또는 `A` `D`) 차선 변경, `Enter` 시작/재시작, `Esc` 메뉴, 모바일은 화면 좌/우 터치.

### 리소스
차량과 도로변 오브젝트는 **외부 이미지 없이 Canvas 2D로 직접 생성**합니다
(`racing/cars.js`, `racing/scenery.js`). 외부 요청이 없어 정적 배포에서 로딩 실패가 없습니다.

- **차량**(위에서 본 모습): 차종마다 실루엣(코/어깨/꼬리 폭, 캐빈 위치, 축거)이 다릅니다.
  공통으로 앞이 좁고 측면은 곧게 뻗는 실차 비율, 보닛 크리스와 도어 라인, 크롬 윈도우 트림,
  길게 흐르는 광택 하이라이트, 헤드램프/리어 램프, 차체 밖으로 살짝 보이는 타이어를 그리고,
  차종별 고유 장식을 얹습니다 — SUV·왜건의 루프랙, 택시의 루프사인과 측면 체커,
  머슬의 보닛 스쿠프와 레이싱 스트라이프, 쿠페·스포츠카의 리어 스포일러, 밴의 루프 벤트.
  픽업/카고트럭은 캡 + 개방형 적재함(금속 데크 리브와 측면 게이트), 탑차는 캡 + 박스,
  세미트레일러는 트랙터 + 킹핀 + 긴 트레일러, 오토바이는 페어링·윈드스크린·금색 포크,
  스쿠터는 전면 실드와 배달 박스까지 그립니다
- **도시 건물**: 옥상면 + 오른쪽/아래 벽면 압출 + 길게 드리운 그림자로 항공사진처럼 보이게 하고,
  옥상에는 기계실 · 실외기 · 헬리패드 · 물탱크를, 벽면에는 창문 격자를 그립니다
  (빛 방향은 우하단으로 통일)
